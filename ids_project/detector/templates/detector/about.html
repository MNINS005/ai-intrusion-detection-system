About This Project

🤖 Model

Isolation Forest trained on the NSL-KDD dataset. It isolates anomalies by randomly partitioning features — anomalies require fewer splits and are flagged accordingly.

📊 Dataset

NSL-KDD — the improved benchmark for network intrusion detection, containing 41 features per connection record.

⚙️ Stack

Python · Django · Scikit-learn · Pandas · Bootstrap 5
